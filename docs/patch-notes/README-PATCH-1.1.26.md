# SS-PATCH-1.1.26 — Character Lab generalisation, stage A1

**Install:** Apply directly over the accepted **v1.1.25** build. This ZIP contains files changed in v1.1.26 only. Reload both Character Lab and the game; service-worker cache advances to `sidescroll-runtime-v136`. Do not reset website data. Your original characters, saved rigs, atlas PNGs, animation banks, storage keys and legacy Fox handoff data are untouched until you explicitly edit and Save.

**Implemented:**
- Add an explicit, semantic Character Lab capabilities profile for Biped and Quadruped adapters (`rigFamily`, supported stages, clip/action slots, motion cadence, default speeds, Idle fallback and renderer technique). Legacy `human` and `fox` IDs continue to identify the existing data. This is not yet an arbitrary-skeleton engine.
- Enable **Quick Play for Biped** (Hero 1, Hero 2, local Biped characters) as well as Quadruped, using the current selected character's working Walk/Run/Jump clips. Biped Idle uses a fixed grounded neutral preview because no editable Idle clip exists yet. Play's movement pad, Jump button, speed sliders, ground ruler and status are shared. Switching back to authored work remains non-destructive.
- Fix Biped sparse clip evaluation at fractional frames (the Biped normalizer requires a whole-number reference sample), so smooth in-between playback is safe.
- Biped Walk/Run movement speeds are now editable and saved in the existing Setup, and respected by in-game movement for built-in and custom Bipeds. Values default to the previous 1.15 / 2.85 m/s when absent; no automatic migration, and no change to the game's existing animation, jump physics, collider or renderers.
- The built-in Fox-only export is explicitly labeled **legacy**; its schema is retained unchanged. Canonical docs include the generalisation boundaries and follow-on gates.

**Test on iPhone:** In Character Lab load Hero 1, tap Play, walk/run via horizontal drag and Jump, reverse direction, then adjust speeds, Save, exit/re-enter Play and verify speed persists. Repeat for Hero 2 and a local Biped. Confirm neutral standing Idle. Load Fox and New01 and verify their Play, Save/Discard, animation and meshes still work. In the game choose the saved Biped and verify movement-speed changes apply after reloading the game. Confirm offline reopen of game and editor. Biped Parts/Skin controls remain disabled intentionally; they are not yet authored or runtime-integrated for user meshes.

**Verification/limits:** JS syntax checks and synthetic in-browser DOM execution validated Biped Idle/Walk/Run/Jump, built-in Biped speed Save, Fox Play and a new Biped Play. Browser smoke execution ran with image requests unavailable, so **rendered artwork, touch, WebGL and actual iPhone Safari/offline performance are not verified**. The full cross-family descriptor-driven Rig/Parts/Skin system, arbitrary skeletons, editable Biped Idle, animation list/New Animation/Climb/Pick Up/Put Down/Carry, portable PNG-inclusive exports and animation template re-targeting remain future work.
