# Unplaced art

Art that is kept on purpose but not yet referenced by the game or labs.
Nothing in code points here, so these are never downloaded by players.

- `sidescroll-dressing-atlas.png` — dressing atlas
- `woodland-puzzle-pack.png` — woodland puzzle pack sheet
- `sidescroll-tree-atlas.png` — tree atlas; the game uses the cut
  `sidescroll-tree-01…08.png` files instead. (Was in the splash preload list,
  which downloaded 6.4 MB on every launch for nothing; removed from it.)

When one of these is placed in the game, move it up into `assets/` and reference
it from code by bare filename.
