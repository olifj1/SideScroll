ANIMATION TOOL

Anim Lab

Create named custom characters in the Character Library using quadruped or biped starter rigs and placeholder artwork. Their editing data and animations are separate from the built-in Hero 1, Hero 2 and Fox. Custom characters are currently editor-only, not yet available in the normal game. Changes live in a working copy until Save; Discard restores the current checkpoint. Rig mode owns character scale, collider and structural rest rig; Animate owns clip poses. Fox Play mode instantly tests the current working Idle/Walk/Run/Jump clips and lets Walk/Run ground speed be tuned against animation cadence. Motion Reference can overlay editor-only gait footage by normalised cycle phase. Static Reference provides Hero 1, Hero 2 / Hair and Fox Shape proportion guides, and Fox Handoff can export the current rig plus all Fox clips as one JSON file.
