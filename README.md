# SideScroll

A small woodland side-scrolling adventure, built as an offline PWA with in-browser
authoring tools (Character, Asset, Puzzle, World, Design and Concept Labs).
Hosted on GitHub Pages from `main`; install it to a phone's Home Screen to play.

- **What to work on:** `TASKS.md`
- **What changed:** `CHANGELOG.md` (current version 1.1.27)
- **How the project works / rules for contributors and Claude sessions:** `CLAUDE.md`

## Repository layout
- Project root — the live PWA: pages, scripts, data and all art the game/labs load.
- `docs/` — design and engine docs; `docs/patch-notes/` old per-patch notes; `docs/audits/` one-off audit JSON; `docs/archive/` the old task log.
- `assets/unplaced/` — art kept for future use but not yet referenced by code.
- `review/` — files nothing references; candidates to delete or restore (see `review/README.md`).
