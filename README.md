# SideScroll v1.0.10

Asset Lab precision editing pass.

- Drag empty viewport space to pan around an isolated asset.
- Collision edges now have draggable midpoint handles so a whole edge can move without losing its shape/level.
- Collision point coordinates can be edited numerically in metres with the cyan floor line defined as Y = 0.
- A selected collision edge can be snapped directly to Y = 0.
- Bridge Pair view shows both bridge halves together on the same floor line; click either half to make it the active editable asset.
