# SideScroll v0.2.82

Puzzle exclusion editor repair and completion.

- repaired Edit Exclusion, Add/Disable Exclusion and Add Dressing
- active puzzles now have an editable translucent exclusion floor plane
- centre handle moves the plane in X/Z
- four edge handles resize its width and depth
- procedural trees, grass, bushes and rocks disappear live inside the active exclusion
- manually placed global environment art is not removed
- Add Dressing opens the normal environment library but attaches new dressing to the selected puzzle
- puzzle-owned dressing ignores its puzzle exclusion and loads/unloads with that puzzle
- exclusion settings save with Set Start, linked templates and unique puzzle copies
