# SideScroll patch v1.1.22 — Character Lab / Load reliability

Install this **changed-files-only** release directly over the accepted v1.1.21 files. It renames visible Anim Lab references to **Character Lab**, keeps the Character Library Load list available after opening another character, and makes guarded Save/Discard/Cancel decisions explicit. You can open another character while in Quick Play; the editor safely returns to Setup.

**No saved character IDs, animation banks, storage keys, atlas formats or URL paths are migrated.** This drop does **not** yet add normal-game custom characters or new animations; those remain the next stages. On-device acceptance is still required. See `README-PATCH-1.1.22.md`.
