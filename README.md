# SideScroll v1.0.9

Asset Lab first pass.

- New standalone Asset Lab from the launcher.
- Edit reusable asset height, floor line, collision polygon/depth and gameplay behaviours in isolation.
- Asset Lab saves to the same defaults used by SideScroll.
- Support surfaces are now independent of puzzle/environment category, fixing bridge support/collision setup.
- Broken bridge halves default to Solid + Support Surface once collision is authored.
